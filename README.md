# Taranis Black | Marketing e Conteúdo com IA

**Oracle Next Education · G11 · Rota 2**  
**Autora:** Julio Gustavo Corrêa 

Projeto educacional para a empresa fictícia Taranis Black. O piloto transforma uma pauta técnica sobre ergonomia em três peças adequadas a públicos distintos. O objetivo é avaliar se uma equipe de quatro pessoas consegue reduzir o esforço de adaptação e preservar a identidade verbal da marca.

## Carrossel do piloto

As seis artes em PNG estão na [pasta carrossel](carrossel/). Os textos dos cards e a legenda estão em [Peças do piloto](05-pecas-do-piloto.md).

## Como reproduzir

1. Abra [as instruções do assistente](04-instrucoes-do-assistente.md) e copie o bloco “Texto para copiar no campo de instruções” para o ChatGPT ou Gemini.
2. Anexe o artigo-semente e o catálogo do kit oficial. Os arquivos-base são distribuídos no challenge.
3. Envie a mensagem de teste e compare as saídas com os critérios da [tabela de evidências](07-evidencias.md).
4. Revise as peças antes de publicar. Os impactos no negócio são resultados esperados do piloto.

## Entrega do challenge

Use o template oficial da Rota 2 no Google Docs para a entrega. Preencha as seções com o relatório, adicione os prints do teste à tabela de evidências e compartilhe com acesso de leitura para qualquer pessoa com o link. Cole a URL do Google Docs na Alura, conforme o aviso da tela de entrega. O repositório serve como versão de portfólio.
